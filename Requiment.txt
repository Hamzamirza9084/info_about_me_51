====================================================
PRACTICAL: GOOGLE CLOUD MONITORING & ALERTING
====================================================

Step 1: Enable Monitoring API
- Open the Google Cloud Console.
- Navigate to "API & Services" > "Dashboard" and click on the "+ Enable APIs and Services" button.
- Search for "Monitoring API" and enable it.

Step 2: Create a Monitoring Workspace
- In the Google Cloud Console, navigate to "Monitoring" > "Dashboards".
- Click on "Create Dashboard".
- Add charts and widgets in your dashboard based totally on your monitoring requirements.
- In the chart, select a metric and select a metric in Search:
  CPU in VM instance -> Metric: CPU Utilization -> Apply -> Apply.

Step 3: Alerting
- Select "Alerting" and go to "Policy" and "Create Policy".
- Select a metric in VM instance: Metric -> CPU Utilization, Apply.
- Rolling window function: set a Max, click Next button.
- Set a threshold value, click Next button.
- Set a notification channel: Email, give a notification subject title -> "CPU - Utilization".
- Check mark on "Notify on incident closure".
- Set a summary.
- Policy severity level -> Critical. Name the alert policy as -> "CPU - Utility".
- Click on the Next button, then click on the "Create Policy" button.
- Go to Explore -> Log Explorer.

Step 4: Create Logs
- Navigate to Logging > Logs Explorer.
- Write a query that isolates the exact logs you want to count, and run it to verify.
- Above the query results, click the "Create Metric" button.
- Give your metric a name, choose Counter as the metric type, and click "Create Metric".
